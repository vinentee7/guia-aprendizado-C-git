# Apendizado com C

## Objetivo
O objetivo deste repositório não é apenas apresentar a sintaxe da linguagem C, mas ajudar o leitor a desenvolver raciocínio lógico e compreender como um programa funciona.

Ao longo dos estudos, serão abordados conceitos como:

Estrutura básica de um programa em C;
Variáveis e tipos de dados;
Entrada e saída de dados;
Operadores;
Estruturas condicionais;
Estruturas de repetição;
Funções;
Arrays e matrizes;
Strings;
Ponteiros;
Structs;
Alocação dinâmica de memória;
Recursividade;
Estruturas de dados;
Pilhas e filas;
Árvores;
Algoritmos de busca;
Algoritmos de ordenação;
Exercícios de lógica e resolução de problemas.

Novos conteúdos poderão ser adicionados conforme o desenvolvimento do repositório.

## Público-alvo
Este material é indicado principalmente para:

Universitários que estão iniciando ou revisando conteúdos de programação em C;
Estudantes de cursos técnicos e áreas relacionadas à tecnologia;
Concurseiros que precisam revisar lógica de programação, algoritmos e linguagem C;
Pessoas que já possuem algum contato com programação, mas desejam fortalecer sua base;
Iniciantes que desejam aprender C através de exemplos e exercícios práticos.

Não é necessário possuir conhecimento avançado de programação para acompanhar o conteúdo. Os tópicos serão organizados de forma gradual, partindo dos conceitos mais básicos.

## Pré-requisitos
O material foi pensado para pessoas que não tem conhecimento ou que precisão de uma revisão
portanto, não precisa ter base alguma antes de começar os estudos.

## Como navegar
Você pode seguir os conteúdos na ordem apresentada nas pastas ou utilizar o repositório apenas como material de consulta e revisão.
Para quem está começando, o ideal é acompanhar os assuntos progressivamente, pois alguns conteúdos dependem de conceitos apresentados anteriormente.
Para quem já possui experiência com C, os módulos podem ser utilizados de forma independente para revisão, prática ou resolução de exercícios.
